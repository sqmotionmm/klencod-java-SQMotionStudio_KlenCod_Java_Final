# SQ Motion Studio — Java prototype

مشروع Android مكتوب بـ Java، مع واجهات أصلية مستوحاة من الصور المرفقة:
- شاشة المشاريع: فتح، إعادة تسمية، حذف، وإنشاء مشروع.
- نافذة إنشاء مشروع مع النسبة والدقة وFPS.
- محرر بمعاينة شبكية وخط زمني وإضافة طبقات Solid/Text/Shape/Media.
- تحريك العنصر باللمس وتعديل X/Y/Scale/Rotation/Opacity.
- إضافة keyframes وتصدير/استيراد ملف مشروع JSON بامتداد `.kf`.
- حفظ صورة المعاينة بصيغة PNG من منتقي الملفات.
- إعدادات أساسية للجهاز واللغة وحجم الواجهة.

## البناء
افتح المجلد `sqproj` في Android IDE يدعم Gradle ثم نفّذ `assembleDebug`. تم تصحيح إنشاء عناصر Spinner في Java لتجنب خطأ `setAdapter` السابق.

يمكن أيضًا رفع المشروع إلى GitHub وتشغيل سير العمل من تبويب Actions عبر `Build Android Java APK`، ثم تنزيل artifact باسم `klencod-java-debug-apk`.

## ملاحظات مهمة
هذه نسخة أولية Java وليست بديلًا كاملًا عن KeyFlow. تصيير MP4 الحقيقي، تطبيق keyframes على الحركة أثناء التشغيل، دعم ملفات الفيديو والصوت داخل المعاينة، والترجمة الكاملة للواجهة ما زالت تحتاج تطويرًا. ملف `.kf` هنا تنسيق JSON خاص بهذه النسخة ولا يُضمن توافقه مع KeyFlow الأصلي. لم يتم تأكيد البناء في بيئة العمل هذه بسبب تعذّر الاتصال بتنزيل Gradle.
